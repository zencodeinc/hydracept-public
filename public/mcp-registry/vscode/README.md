# Hydracept for VS Code / GitHub Copilot

Official MCP Registry listing name: `com.hydracept/vscode`.

Remote Streamable HTTP endpoint:

```text
https://api.hydracept.com/mcp/vscode
```

Auth is OAuth 2.1 with Dynamic Client Registration and PKCE S256. VS Code discovers
protected-resource metadata and registers as a public client. Do not send a Hydracept
API key to this URL.

Setup: https://hydracept.com/vscode/

This gallery surface is directory-safe: text, reasoning, structured execution, domains,
quotes, durable jobs, and receipts. It does not generate images, video, audio, or 3D.

The separate listing `com.hydracept/hydracept` covers the API-key hosted MCP and PyPI
stdio package and is not this connector.
